# Application Screenshots

This folder documents the main Campus Canteen Ordering System screens. Each screenshot should show a real part of the student or admin workflow and help a reviewer understand what the application can do.

## Screens to capture

|---|---|---|
| `01-home.png` | Home | The canteen landing page, key actions, and overall visual theme. |
| `02-menu.png` | Menu | Food and drink listings, categories, and menu search. |
| `03-cart.png` | Cart | Selected items and quantities before checkout. |

Save captures in this folder as PNG or JPG files. Use the suggested numbering to keep them in workflow order. Crop out unrelated desktop content and make sure text is readable. Do not include real passwords, tokens, or private student information in screenshots.
